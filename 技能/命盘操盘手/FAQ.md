## 入门 6 问

**Q1: 我完全没基础，能用吗？**
A: 能。30 秒上手——给出生辰（年/月/日/时）+ 性别，AI 套财管话术给你出"出厂财报 + 年度行情 + 3 条调仓建议"。术语听不懂没关系，AI 翻给你听。

**Q2: 必须装 node 吗？**
A: 想要精准盘面就装（`calculator/dist/` 已预编译，`npm install` 后 `node dist/run-chart.js ...` 即可）。没 node 也能用——AI 走"纯提示词降级档"按描述给方向，精度降一档但够玩。

**Q3: 输入会不会被存下来 / 泄露？**
A: **不会**。单次会话无状态，不跨会话记忆，不读你私人文件 / 知识库。所有示例盘都是虚构脱敏的。

**Q4: 八字准不准？**
A: 命理是文化框架，不是科学。本工具给的是"倾向提示"——十神结构 + 五行喜忌 + 区域 Beta 参考，别当判决书。决策永远你自己拿。

**Q5: 输出末尾那段「⚠️ 本内容为 AI 生成…」是啥？**
A: 监管要求的 AI 生成内容显式标识（2025《人工智能生成合成内容标识办法》），提醒你这是 AI 给的文化体验，不是人生建议。

**Q6: 江服新生怎么用？**
A: 给出生辰 + 出生地（具体到镇）+ 父母职业大致方向 + 经历 1-2 件，AI 走"天时地利人和"三维给你平调建议。迎新摆摊直接搬 `examples/index.md` 的 5 个示例对话。

## 报错 / 边界 6 问

**Q7: 时辰忘了/不知道，几点都行吗？**
A: 时辰不定可以——按日主 + 大运看，正午 12 点当默认起盘，要改告诉 AI。

**Q8: 写了"2 月 30 日"或"13 月"怎么办？**
A: 这种边界日期会报错。AI 帮你改 28 或 29 重跑；农历生日给年份 + 节日名（如 `1995 春节`），AI 帮你换算。

**Q9: 时辰写成 PM 12 / 12am 之类的？**
A: 24h 制：12:00 = 正午，00:00 = 子时。AI 自动转。

**Q10: 我只记得大概年份（"1990s 生日"）？**
A: 具体到日才能起盘。没具体日，给个大致年份 + 大运区间参考，AI 也能给个粗方向。

**Q11: 输入未来日期 / 跨年出生怎么办？**
A: 未来日期会被拒（生日超过今天），复核下。跨年（如 12-31 23:30 出生）AI 自动用"晚子时次日派"处理。

**Q12: 跑出空盘 / 报错堆栈？**
A: 重输生辰试试；如果一直崩，把输入 + 报错发给 AI，AI 会按 SKILL.md 的「错误处理」表降级或重试。

## 进阶 4 问

**Q18: 怎么挑职业 / 专业？**
A: 详见 `profession-library.md`（300+ 职业，按国家职业大典 8 大类）和 `major-library.md`（12 学科门类 200+ 专业）。同一份盘用对应职业的操盘语言讲，对方秒懂。

**Q19: 13 门学科透镜从哪来？怎么开？**
A: 心理学（MBTI）/ 历史学 / 社会学 / 游戏化 + 经济学金融 / 教育学 / 脑科学 / 传播学 / 法学 / 设计学 / 组织行为学 / 数据科学 / 体育医学。详见 SKILL.md「多视角熔接」段。

**Q20: 引擎能改吗？怎么改？**
A: 可以。`calculator/` 是 TypeScript 源码，模块对应：
- `bazi-engine/` 排盘核心
- `bazi-enrich/` 旺衰 / 格局 / 五行 / 调候
- `yiqi-core/` 四柱 / 大运 / 纳音
- `bazi-enrich/flux.ts` 流年/流月/流日
改完跑 `npm run build`（tsc）重新编译 `dist/` 即可生效。

**Q21: 江服新生没出生地到镇怎么办？**
A: 给到县/区也行。地利维度"地利 = 出生地 → 查内置「地支方位五行原型表」"，精度降一档但不影响大局。
