# 职业底色库（扩展版 · 几百个职业速查）

> 本库是 SKILL.md「职业底色库」的**完整扩展版**。SKILL.md 里只留 8 行速查表 + 指针，全部职业枚举、映射逻辑都在这。
> 用户原话："职业都有几百个职业估计" —— 对。《国家职业分类大典（2022 版）》共 **1639 个职业**（8 大类 / 79 中类 / 449 小类），其中 **97 个数字职业、134 个绿色职业**。本库按 8 大类框架枚举 **300+ 现代职业**，并标注其典型十神底色 / 五行底色 / 紫微官禄星，可直接套「命盘操盘手」的操盘语言翻译。
>
> **映射逻辑（怎么来的）**：职业底色 = 该职业的「核心动作」→ 映射十神（现金流结构）/ 五行（行业属性）/ 紫微官禄星（事业原型）。公开框架归纳自：国学之家、八字派、ba-zi.ai（十神→职业）、易师汇 / 易象乾坤（五行→行业）、FateMaster / starnum / qimenxuanxue（紫微官禄 14 主星→职业原型）。

## 四、怎么自己扩一个新职业（三步法）

1. **抓核心动作**：这职业每天在干嘛？（例：主播 = 表达+收打赏）
2. **映射十神/五行**：表达=食伤/伤官，打赏=偏财；属火（曝光）/水（流动）→ 伤官+偏财，火水，贪狼星。
3. **套模板翻译**："你是才华即时变现型（伤官配偏财），镜头前越真越赚，但偏财分流要穿盔甲（别被 MCN 坑）。"

不用穷举，按"动作归类"即可无限扩。本库 300+ 条是示范，不是上限。
