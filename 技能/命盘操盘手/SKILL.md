# 江西服装学院—命盘操盘手Skill

> 一句话记住：**你的生辰不是命运判决书，是一份「出厂财报 + 年度行情」；再叠上你所在的时代、脚下的
> 土地、走过的经历，就是一张「天时地利人和」操盘地图。** 盘面由算法精准产出，怎么读，由 AI 套
> 一套「财管语言」给你——用你听得懂的资产配置 / 仓位 / 现金流话术，说清你该进攻、防守、还是再平衡。

> 🏫 **参赛定位（宝藏母校 Skill 大赛 · 创意脑洞赛道）**：本 Skill 由**江西服装学院**在校学生为
> **同校新生**打造，定位「迎新破冰 + 财商启蒙」趣味工具——用财管专业的视角把八字读成"出厂财报"，
> 帮新生在轻松氛围里做自我探索、认识自己、顺带启蒙财商。脑洞向，符合创意赛道"越大越炸"。

## 快速上手（30 秒版）

**最简调用**（直接复制发给 AI）：
> 请按 SKILL.md 给 `[你的生辰] [男/女]` 出一份「出厂财报 + 年度行情」+ 3 条调仓建议。

- **必填**：年/月/日/时 + 性别。例：`2005-3-12 8:30 男` / `2003-5-18 15:20 女`（均为虚构示例，不对应任何人）
- **选填**（越详细越准）：出生地（省/市/县/**具体到镇**）、在哪儿读书（城区/乡镇）、父母职业/家庭氛围、个人经历 1-2 件、行业
- **输出**：出厂财报卡 + 年度行情 + 3 句平调建议 + 收口「决策你自己拿」+ AI 生成标识 footer
- **注意**：`dist/` 已预编译（**不用 tsc build**），但**首次必须 `npm install`**——紫微斗数依赖 `lunar-typescript`，
  漏装会报 `Cannot find module 'lunar-typescript'`。两条路径二选一：
  - **完整盘（八字 + 紫微 + 流年流月流日）**：`cd calculator && npm install`，然后 `node dist/run-chart.js ...`
  - **只要四柱（零依赖，不装任何包）**：`node -e "const {calc}=require('./bazi-engine/engine.js'); console.log(calc(y,m,d,bjH,bjM,lon))"`
    ——注意 `calc` 收的是**位置参数**不是对象，顺序为 `年, 月, 日, 北京时间小时, 分钟, 出生地经度`
    （经度：北京 `116.4`、上海 `121.5`、成都 `104.1`；其他城市自行查经度）

### 完整对话触发示例（用户会怎么开口 → 你怎么接）

用户**不会**照模板说话，以下是真实场景的完整对话示例：

**场景 1：直接报生辰（最常见）**
> 用户：「我是 2005 年 3 月 12 号早上 8 点半生的，男的，你帮我看看」
> → 识别：生辰齐全（2005-03-12 08:30 男）→ 直接排盘 → 走 intake 问出生地/经历 → 出报告

**场景 2：只说大概，缺时辰**
> 用户：「我 2002 年冬天生的，具体几点不记得了」
> → 识别：缺月日时 → **不要报错**，先按「只知道年份」给大运区间粗判，同时问：
> 「大概几月？时辰不记得也没关系，我按正午 12 点先起一版，你后面问到家人再告诉我我重跑。」

**场景 3：用本工具的黑话开口**
> 用户：「给我排个出厂财报」「用操盘手视角看看我的盘」「看看我的五行缺啥」
> → 识别：命中 triggers（出厂财报 / 操盘手视角 / 五行）→ 先问生辰，再排盘

**场景 4：带场景来问（江服新生典型）**
> 用户：「我是江服新生，想做自媒体，不知道适不适合」
> → 识别：身份（江服新生）+ 卡点（自媒体方向）→ 问生辰 + 出生地 → 排盘后
> 用「职业底色库」自媒体的操盘语言讲（食伤 = 输出能力、财星 = 变现路径）

**场景 5：跨场景 / 不合规则**
> 用户：「我该不该跟女朋友分手」「帮我选只股票」
> → 识别：命中「不适用场景」→ **明确拒绝 + 给替代**：
> 「这个我不给建议——本工具只做文化体验和自我探索，感情 / 投资决策不该交给它。
> 要是你想聊聊自己的性格倾向和精力该怎么分配，我倒是可以说说。」

**场景 6：多轮追问（同一份盘换角度）**
> 用户（第一轮排完）：「那我今年适合考证还是实习？」
> → 识别：已有盘面 → 不必重排，直接在该盘上走流年流月 → 给「攻 / 守」建议

## 输入规范（照这个喂，不崩）

合法格式：`YYYY-M-D H:M` + `男/女`（24h 制）
- 时辰 [0, 24)，分 [0, 60)，月 [1, 12]，日 [1, 31]
- 年份 [1900, 2100]
- 出生地越细越准（具体到镇）

**烂输入怎么办** → 见下面「错误处理」表。

### 引擎侧校验（代码已实现，不是只写在文档里）

`run-chart.ts` 在排盘前会跑 `validateBirthInfo()`，拦截以下情况并输出**结构化错误**（不是堆栈）：

| 拦截项 | 例子 | 是否拦截 |
|:--|:--|:--:|
| 年份越界 | `--year=1899` / `--year=2101` | ✅ |
| 月份越界 | `--month=13` / `--month=0` | ✅ |
| **日期不存在** | `--month=2 --day=30`、`--month=4 --day=31` | ✅ |
| **闰年判断** | 2005-02-29 拦 / **2024-02-29 放行** | ✅ |
| 时辰越界 | `--hour=99` | ✅ |
| 分钟越界 | `--minute=60` | ✅ |
| **非数字输入** | `--year=abc`（NaN 会穿透大小比较，已单独拦） | ✅ |
| 性别非法 | `--gender=xxx`（自动降级为 female） | ✅ |

### 健壮性外壳：`safe-run.js`（重试 / 超时 / 降级）

`run-chart.js` 只做排盘。要**重试、超时、优雅降级**，用外壳 `safe-run.js`：

```bash
cd calculator
node safe-run.js --year=2005 --month=3 --day=12 --hour=8 --minute=30 --gender=male
node safe-run.js ... --timeout=20000 --attempts=5   # 可调超时/重试次数
SKILLHUB_DEBUG=1 node safe-run.js ...               # 调试时才带内部 stderr
```

**它具体做了什么（都有代码实现）**：

| 机制 | 实现 |
|:--|:--|
| **重试** | 默认最多 3 次，指数退避 300ms → 600ms。**输入类错误不重试**（重试也没用，直接返回） |
| **超时** | 默认 15 秒，`spawnSync` 带 `timeout`，超时按 `TIMEOUT` 分类返回，不挂死 |
| **结构化错误** | 输出 `{ok:false, error:{category, what, why, next[], degraded:true}}`，**What-Why-Next 三段式，不甩堆栈** |
| **优雅降级** | 引擎彻底不可用时带 `degraded:true`，AI 据此切「纯提示词降级档」（精度降一档但仍能给身强身弱/喜用神粗判） |

**退出码**：`0` = 成功 ／ `1` = 输入问题（改输入，别重试）／ `2` = 引擎或环境问题（可重试或降级）。

**边界回归测试**（10 例，全部通过）：

```
正常 2005-03-12        exit=0  OK   | 四柱 乙酉己卯乙未庚辰
2月30日(不存在)        exit=1  FAIL | INPUT_VALIDATION
2月29日(2005非闰年)    exit=1  FAIL | INPUT_VALIDATION
2月29日(2024闰年)      exit=0  OK   | 四柱 甲辰丙寅癸亥丙辰
4月31日(不存在)        exit=1  FAIL | INPUT_VALIDATION
时辰99(越界)           exit=1  FAIL | INPUT_VALIDATION
年份abc(非数字)        exit=1  FAIL | INPUT_VALIDATION
年1899(下界外)         exit=1  FAIL | INPUT_VALIDATION
月13(越界)             exit=1  FAIL | INPUT_VALIDATION
分60(越界)             exit=1  FAIL | INPUT_VALIDATION
```

## 不适用场景（这几种别来）

- ❌ 想用它做**重大决策**（投资/择业/婚姻/健康/生死）——只供文化体验
- ❌ 推给**未成年人**单独使用——定位 18+ 大学生群体
- ❌ 批量商业化 / 收费解读 / 破灾改运 / 开光饰品——违反合规规则
- ❌ 没有 node 环境又想要**精准**盘面（只能走"纯提示词降级档"，精度降一档）
- ❌ 当**科学结论**用——命理是文化框架，不是科学

## 错误处理（AI 收到烂输入怎么接）

### 四条铁律（照 Amazon Alexa / Slack / CallSphere 的对话设计规范）

1. **What-Why-Next 三段式**——每次出错都说清三件事：
   - **发生了什么**（用人话，不甩技术错误）
   - **为什么**（非技术性解释，不甩 `TypeError` / `HTTP 500` / 堆栈）
   - **下一步你能干嘛**（给 2-3 个明确选项：重试 / 改说法 / 换降级方案）
2. **绝不责怪用户**——不说"你输错了""格式不对"，改说"我没看懂这块，你换个说法我再来"。
3. **分级降级，不一次问到底**——
   - 第一次出错：简单复述 + 请你再说一次
   - 第二次还错：多解释一层，给具体例子
   - 反复失败：主动给替代方案（如"时辰不知道就先按正午起盘，后面能改"）
4. **允许不完整输入 + 主动澄清**——不要逼用户一次给全。缺时辰就先按日主 + 大运看，
   缺具体日就给年份区间参考。歧义要主动问（"你说的 12 点是**中午**还是**半夜**？"）。

### 常见情况对照表

| 情况 | 错误接法 ❌ | 正确接法 ✅（What-Why-Next） |
|---|---|---|
| 不知道时辰 | "时辰必填" | "时辰不知道没关系——我先按**日主 + 大运**给你看，正午 12 点当默认起盘。等你问到家人确认了，告诉我一声我重跑，结论会更准一点。" |
| "2 月 30 日" | "日期非法" | "2 月没有 30 号这天（闰年最多到 29）。我按 **28 号**先起了一版，你看看对不对？要改成 29 号跟我说。" |
| 时辰写 "PM 12" | "格式错误" | "我按 24 小时制理解成**中午 12:00** 了。如果你想说的是**半夜 0 点**，告诉我一声——晚子时日柱会推到第二天，盘面会不一样。" |
| "1990s 生日" | "需要完整日期" | "具体到哪年哪月哪日才能起盘。你先给个大概年份，我按**大运区间**给你个粗方向；等拿到准确日子再细看。" |
| 未来日期 | "日期超出范围" | "这个日子还没到呢——生日应该是过去的。你核对一下年份，是不是把 2026 写成了 2016？" |
| 空盘 / 引擎报错 | 甩堆栈 | "盘面这会儿没跑出来，不是你输入的问题。**已经跑出来的部分我给你留着**，你再说一次生辰我重跑；要是还不行，我按纯描述给你个方向（精度降一档）。" |
| 农历生日 | "只支持公历" | "我这边吃公历。你告诉我**年份 + 节日名**（比如 `1995 春节`、`2001 中秋`），我帮你换算成公历再起盘。" |
| 多胞胎 / 同盘不同人 | "结果相同" | "同一个时辰出生的盘面确实一样，但人不一样。你跟我说说你的**经历和眼下卡在哪**，我按你自己的情况给差异化建议。" |
| 出生地只给到省 | "信息不足" | "够用，我先按省级方位给你地利参考。你要是能给到**市/县**，方位会更准一点，没有也不影响大局。" |
| 网络 / 引擎不可用 | "服务异常" | "引擎这会儿连不上，我没改动你任何东西。先用**纯提示词降级档**给你按描述讲讲方向（精度降一档），等引擎恢复了再出精准盘面。" |

## 这是什么

一个把中国传统文化「八字 / 紫微斗数」用**财管框架**重写的 Skill。给一个人排个盘，翻译成一份
"出厂财报 + 年度行情"——看他是重仓单一赛道、还是该补点进攻仓、眼下这段日子该动还是该守。
**纯文化体验，不算命不吉凶。**

它不是"算命计算器"，而是一套**人生财务诊断模型**：盘面是原始数据（确定性、可复现），真正产出
是"用财管框架（资产配置 / 风险偏好 / 现金流）重新解构这份数据"之后给你的那几句引导。
在此基础上，本 Skill 进一步把单层排盘升级为 **天时地利人和三维立体框架**——盘面仍是引擎精准产出
（不变），新增的「时代背景」「地理方位」「个人经历」是**解读层**，用内置原型表 + 可选联网搜索落地
（无网也能跑），让引导从"你是谁"落到"你该在何时、何地、联合谁、做啥"。

> 为什么是财管而不是"自我认知"？因为市面上 99% 的八字工具都在说"自我认知 / 心理疗愈 /
> 知命造命"，这套已经烂大街了（小红书同款话术）。本 Skill 换一个**没人用过的硬核壳**：
> 把八字当一份资产负债表来读——这恰恰是你（财管专业）的专业语言，别人是 AI 画张 K 线图
> 凑热闹，你是用真框架解构。**这是差异化护城河。**

> ⚠️ **隐私红线**：本 Skill 所有示例盘均为**虚构 / 脱敏演示**，不对应任何真实生辰（含作者本人）。
> 公开文档里绝不放任何真人八字。人和维度只来自用户**当轮自述**，不读任何隐私文件、不跨会话记忆。

**适用场景**：江西服装学院迎新周社团摆摊、班级破冰、财商 / 传统文化主题团日；自我探索趣味辅导、商赛 / 创业
团队的"性格—分工"轻量参照、不同职业人群的"职业倾向"文化参照、跨地域 / 跨行业人群的"该留该走"
文化讨论。

## 输入

> 设计原则：**专业的东西翻译给大众听懂**。下面每一项都配了一句大白话，让用户知道"为什么 AI 要问这个"。

- **必填**：出生年、月、日、时（阳历 / 农历均可）+ 性别（影响大运顺逆）
- **出生地 / 成长地（越具体越好，调「地利」维度）**：
  - 具体到「省 / 市 / 县 / 镇」都行，比如"江西省某县清溪镇""在县城一中读书""城区还是乡镇"
  - 大白话：**你脚下这块土适合种什么**——留本地还是往外走，AI 结合盘面喜用神给你说
- **家庭环境（人和的起点，调「人和」维度，可选但强烈建议）**：
  - 父母职业 / 家庭经济底色（宽裕 / 普通 / 紧巴）/ 成长氛围（放养 / 严管 / 书香）
  - 大白话：**你出厂时的"操盘搭子"和"原始安全垫"**——很多人的十神底色（印比/劫财）是从家庭长出来的
- **个人经历（人和的素材，调「人和」维度，可选）**：
  - 近一两年最有体感的一件事 / 一个转折（带团队踩坑、考证上岸、换城市…）
  - 大白话：**你踩过的坑、攒过的底气**——AI 把它钉到具体十神叙事上，盘才"活"成你这个人
- **所在行业 / 想做的方向（调「天时·时代」维度，可选）**：考公 / IT / 自媒体 / 财管 / 实业…
- **不需要姓名、身份证，不收集任何隐私**

> 越全越准：只给生辰 = 只能出"你是谁"；加上出生地 + 家庭 + 经历 = 出"你该在何时·何地·联合谁·做啥"。
> 不愿说的项跳过，降权重，不影响出生盘精准度。

## 专业术语 → 大白话翻译（读前先懂 · 让大众接住）

> 命理黑话普通人听不懂，是本 Skill 最该破的墙。下面把核心概念翻成"人话"——**专业的东西翻译给
> 大众听懂**，是这次升级的核心。AI 在 intake 和解读时，优先用右列说法，黑话只在括号里补一句。

| 专业词 | 大白话（给用户的话） | 对应操盘比喻 |
|---|---|---|
| 日主（甲/乙木…） | 你这人本身的内核、出厂设定 | 你是哪只"股票" |
| 五行（木火土金水） | 你身上的五类能量 / 五类资产 | 你的五类持仓 |
| 身强身弱 | 你天生能扛事、主动出击的程度 | 你的风险偏好 / 本金足不足 |
| 十神（正偏财·劫财·食伤·官杀·印） | 你赚钱的五种路数 + 身边五种关系 | 你的现金流结构 + 五种搭子 |
| 格局 | 你的主打打法 / 商业模式 | 你的投资策略标签 |
| 大运 | 十年一段的人生主浪 | 季线（十年趋势） |
| 流年 / 流月 / 流日 | 今年 / 本月 / 今天的运气节奏 | 年 / 月 / 日 K 线 |
| 调候用神 | 你目前最该补的那块能力缺口 | 该补的仓位 |
| 喜用神 | 对你有利的能量（人 / 事 / 地 / 行） | 该加仓的方向 |
| 地利（出生地五行） | 你脚下这块土适合种什么 | 区域赛道 Beta（留还是走） |
| 人和（家庭 + 经历） | 你身边的人和走过的路 | 你的操盘搭子 + 踩过的坑 |

> 一句话锚定：**盘是财报不是判决书，上面每个词都能翻成"你这个人"的某一面。**

## 引导式问答 intake（Skill 被调用时 AI 现跑 · 核心升级 · 反复互动贯穿全程）

> 本 Skill 不是"丢个生辰就吐一段模板"。被调用时 AI **先引导用户把背景说出来，再结合回答给方案**。
> 同一个盘，对"镇上长大、父亲个体户"的人和"省会书香门第"的人，价值点完全不同——不先问就瞎给
> 等于废话。**本 Skill 支持两种运行模式，覆盖"能多轮对话"和"不能多轮"的所有智能体**（见「运行环境适配」）。

### 模式一 · 多轮深问（能追问的 agent，如 WorkBuddy / CodeBuddy / 带对话的 agent）
> 把提问拆成多轮，**像聊天一样层层深挖、贯穿全程**——不是开场问一次就完，是排盘后交付时还回扣确认。
> 用户没生辰也能先聊诉求，排盘可后置。

- **第 0 步 · 破冰（30 字）**："这是份人生财报不是算命。先聊两句你的现状 + 出生地 + 家庭，我给更对口的。"
- **第 1 轮 · 身份 + 生辰**：问身份（学生 / 在职哪行 / 创业 / 退休）+ 生辰（年/月/日/时 + 性别）。
  → 拿到生辰可先排盘，也可看完用户想聊啥再排（排盘可后置）。
- **第 2 轮 · 深挖地利（出生地 / 成长环境）**："你具体哪出生的？省/市/县/镇都行，在哪儿读书、城区还是乡镇？"
  → 结合「地支方位五行原型表」定方位五行；用户自述"某县清溪镇 / 县城一中 / 乡镇"翻译成五行意象
  （山水涵养 / 文教氛围 / 邻里人情）。不愿说跳过，降权重。
- **第 3 轮 · 深挖人和（家庭环境 · 人和起点）**："你家里啥情况？父母做啥的、宽裕还是紧巴、放养还是严管？"
  → 这是人和的起点：很多人的印比 / 劫财底色从家庭长出来（父亲个体户 = 偏财底、母亲教师 = 印底、
    严管 = 官杀底）。
- **第 4 轮 · 深挖经历（人和素材）**："近一两年最有体感的一件事？带团队踩坑 / 考证上岸 / 换城市都行。"
  → 钉到十神叙事（踩坑 = 劫财被分，该穿盔甲；上岸 = 加印见效）。
- **第 5 步 · 融合输出 + 回扣确认（贯穿的反复互动）**：产出三维方案后，**当场回扣一句确认**
  （"你说在镇上长大、父亲个体户，所以你劫财底子来自家庭、宜穿盔甲——对不对？"），用户纠正 / 补充，
  AI 再微调。**这就是"反反复复提问贯穿整个 skill"的落地**。
- **风格锚（可选随时问）**："你平时偏稳扎还是敢冲？" → 校准身强身弱措辞（身弱但自称敢冲 = "假强"，别加杠杆）。

### 模式二 · 单轮问卷（不能多轮 / 一次性 prompt 的 agent，如某些纯提示词 agent）
> 不能追问就把"全维度问卷"一次性列给用户，用户填完一次性回复，AI 再排盘解读。问卷覆盖所有维度：

```
请按下面填（带 * 必填，其他可选，不填跳过）：
* 出生：年 月 日 时（阳历/农历）+ 性别
* 身份：学生 / 在职(哪行) / 创业 / 退休
* 出生地：省/市/县/镇 + 在哪儿读书 + 城区/乡镇
* 家庭：父母职业 + 经济底色(宽裕/普通/紧巴) + 成长氛围(放养/严管/书香)
* 经历：近一两年最有体感的一件事
* 卡点：最想搞清楚的事（选方向/人际/精力/该不该动/好奇）
* 行业：想做的方向（考公/IT/自媒体/财管…）
* 风格：稳扎 / 敢冲
```
用户一次性回复 → AI 走「解读框架」全流程产出（含天时地利人和）。

### 通用原则
- **先问后解**：用户没生辰也能先聊诉求，排盘可后置。
- **反复互动贯穿**：多轮 agent 在交付后回扣确认；单轮 agent 用问卷一次性覆盖——两种都保证"背景问全再解读"。
- **单次会话无状态**：问答只本轮生效，不存、不跨会话记忆（隐私红线）。人和只取当轮自述，绝不读私人文件 / vault。

## 天时地利人和 · 三维立体操盘框架（主架构 · 不破精准底子）

> 八字只算"你是谁"（天时之出生维度）。但一个人成事 = 天时（你是谁 + 你在时代什么位置）× 地利
> （你在哪）× 人和（你经历过什么 + 跟谁）。本 Skill 把单层排盘升级为三维：盘面仍是引擎精准产出
> （不变），新增的「时代」「地理」「人和」是**解读层**，用内置原型表 + 可选联网搜索落地（无网也能跑）。

### 维度一 · 天时（两层：出生盘 + 时代盘）
- **出生盘（引擎）**：八字四柱 + 大运 + 流年流月流日（flux 动态行情层）。这一层是"你是谁"，确定性、可复现。
- **时代盘（时代 Beta）**：你出生在「三元九运」的哪一运？当下（参照日年份）又在哪一运？
  - 框架（公开三元九运说）：2004-2023 八白**土**运（地产/基建/制造红利）；2024-2043 九紫**火**运
    （离火：文化/科技/能源变革/AI/虚拟）；2044-2063 一白**水**运（全球流通/跨境）。
  - 每运二十年分「前十年入场红利、后十年深耕存量」。
  - 熔接（新浪观点）："国运是所有人的背景板，你命盘的用神是聚光灯，背景板再华丽灯不亮也白搭"——
    时代只放大/压制你的喜用神，**不决定**你。
  - **取数方式（能力分级）**：① 若运行环境有联网搜索 → 搜「当年宏观趋势 + 用户行业 Beta」
    （如"2026 AI 算力 / 新能源政策"）；② 若无 → 用本文件内置「九运时代原型表」（覆盖 1984-2063，够用）。

### 维度二 · 地利（你在哪 · 具体到镇 / 读书环境）
- **输入**：intake 的「地利深挖」（出生地可到省 / 市 / 县 / 镇 + 在哪儿读书 + 城区 / 乡镇）。不强制；不愿说跳过。
- **落地（两级映射）**：
  - **① 省级查表**：用户所在地 → 查内置「地支方位五行原型表」得省份五行（江西=巳火地、北京=子水/北、
    上海=卯木/东）+ 结合盘面**喜用神**定"宜留 / 宜去"方位：喜木火→东南/南（江西、杭州、厦门），
    喜金水→西北（西安、乌鲁木齐），喜水木→北/东（北京、上海），喜土金→中/西/家乡。
  - **② 镇级 / 成长环境自述翻译（五行意象）**：用户报"某县清溪镇 / 县城一中 / 乡镇"这类具体到镇的信息，
    AI 翻译成五行意象辅助判断——山区水木养印（利学业沉淀）、城区火土利社交输出、沿海金水利流动财、
    乡镇土重利安稳但需木疏。这是"地利"颗粒度细化，不写死规则，作注脚（有 web 可补搜当地产业/人文）。
  - 财管翻译：地利 = 你的"本地流动性 / 区域赛道 Beta"。身弱喜印比者留家乡（借原生人脉安全垫）；
    身强喜财者往喜用神方位去"催旺财星"。
- **取数方式**：省级纯内置表（无需联网）；镇级自述翻译靠 AI 规则估算。

### 维度三 · 人和（家庭环境 + 你经历过什么）
- **输入**：intake 的「家庭和经历深挖」——① 家庭环境（父母职业 / 经济底色 / 成长氛围）② 近一两年经历
  （用户自述，**不读任何隐私文件**）。
- **落地（两层）**：
  - **① 家庭环境 = 人和起点**：很多人的十神底色从家庭长出来。例：父亲个体户（偏财底，敢闯但分流多
    → 宜穿盔甲）、母亲教师 / 书香（印底，吃学习红利）、严管家庭（官杀底，规则感强但易内耗）。
    AI 把家庭结构翻译成十神叙事，作为"出厂安全垫 / 原始搭子"注脚——**这就是你说的"出生家庭环境"维度**。
  - **② 个人经历 = 人和素材**：自述经历映射到十神 / 宫位——"带团队踩坑"→ 劫财被分（正应穿盔甲）；
    "考证上岸"→ 加印见效。这是把"抽象盘"钉到"具体人"的关键。
  - 同一份盘，家庭和经历不同，引导侧重完全不同——人和让盘"活"成这个人。
- **红线**：人和来自**用户当轮自述**，不跨会话记忆、不读 vault（跨智能体不可移植 + 隐私风险）。
  若某平台（如 WorkBuddy）用户主动愿接 vault，那是平台增强项，非核心、不写死。

### 三维合成（操盘结论）
把三层叠一起，产出一句"三维结论"（例）：
> "天时：你这步大运官杀透干（制度内适配）+ 当下九紫火运（文化/科技 Beta 对你喜火有利）；
> 地利：你江西籍（巳火地）本身就是你的喜用神旺地，留本地或往东南都顺；
> 人和：你带过团队踩过坑（劫财被分），说明该穿盔甲别口头默契。
> → 结论：在火运窗口期、留东南地利、联合靠谱搭子（穿盔甲）做文化/技术类事，胜率最高。"

- **紫微斗数命盘**：十二宫（命 / 兄弟 / 夫妻 / 子女 / 财帛 / 疾厄 / 迁移 / 交友 / 官禄 / 田宅 /

    命局四支的刑冲合害 / 三合三会——这是"当下行情"信号
  - 整柱判定（盖头 / 截脚 / 天干生地支等）

**第二段 · 引导（AI 执行「解读框架」交付，见下文）**
- 把上面的补层数据 + 用户 intake 回答（含地利/时代/人和）+ 职业底色库，套「财管 / K线隐喻 +
  多视角熔接 + 天时地利人和」框架，产出：**三维结论一句话 + 配置建议 3 条 + 行动清单**，口吻校园化、
  标注"趣味 / 文化体验"。
- 其中**流年流月流日**用来回答"那眼下这段日子我该进攻还是防守"——把 decade 级的大运，落到

> 盘面是固定的，引导是因盘 + 因人 + 因地 + 因时而异的——所以 SKILL.md 把"怎么用财管语言 + 多视角
> + 职业底色 + 天时地利人和"写死，AI 负责执行。

## 核心逻辑（财管 / K线隐喻 · 主视角 · 底层不变）

本 Skill 把八字读成一份**人生财务体检报告**，底层立场不是宿命论，是"检查工具"——
盘是帮你认识自己风险偏好与资产配置的诊断单，不是判决书。三个支撑来源熔接：

### 1. 五行 = 五类资产（资产配置映射 · 源自新浪 / 马君程公开框架）
把命局五行当成你的"资产组合"，每类有它的波动特征：

| 五行 | 对应资产类别 | 波动特征（风险画像） |
|---|---|---|
| **木**（甲寅乙卯） | 权益类 / 成长股 / 科技 / 文教 / 绿色能源 | 长得快，但遇"灾年"（流年冲克）可能颗粒无收 |
| **火**（丙午丁巳） | 科技股 / 影视 / 互联网 / 高波动标的 | 来钱快去得也快，玩的是心跳 |
| **土**（戊辰戊戌） | 不动产 / 地皮 / 实体 / 定期存款 / 必需品 | 压舱石，轻易不动，抗跌 |
| **金**（庚申辛酉） | 黄金 / 贵金属 / 国债 / 金融 / 硬通货 | 乱世价值显，变现能力强 |
| **水**（壬子癸亥） | 现金流 / 外汇 / 跨境 / 私募 / 专利版权 | 流动智慧，控得住才叫资产，控不住是负债 |

→ 五行缺旺 = 你的组合失衡在哪类。比如木过旺 = "重仓单一成长标的，波动大、易内耗"；
火缺 = "没有高弹性进攻仓，全防守"。

### 2. 身强身弱 = 仓位与风险偏好（马君程"能量诊断"框架）
- **身强** = 你能主动出击、做波段，精力旺；但易过度自信、盲目加杠杆（火旺克金）→
  对策：配**水**（流动性 / 多听不同意见 / 跨境分散）来泄秀生财，别一把梭。
- **身弱喜印比** = 你吃平台和团队红利，不适合单打独斗炒短线、重仓押注单一项目 →
  对策：借团队 / 定投（木）/ 专业机构打理，把"印比"当你的安全垫。
- **旺衰四维** = 财务健康四项体检：得令 = 主业景气、得地 = 底仓扎实（根稳）、得势 = 外部助力
  （天干帮身）、长生 = 周期位置。

### 3. 十神 = 现金流结构
- **正财** = 工资性收入 / 稳定现金流（朝九晚五的活）
- **偏财** = 投机 / 人脉财 / 意外之财（副业、信息差、搭子带来的机会）
- **劫财** = 合作 / 竞争风险——别人来分蛋糕；对策是"穿盔甲"：保险 / 信托 / 可靠合伙靠山
- **印** = 贵人 / 学习杠杆（人力资本投资，考证、跟导师就是加印）
- **食伤** = 变现能力 / 创造力输出（你能把本事卖出钱的那一环）
- **官杀** = 压力 / 规则 / 职业约束（考公、制度内的成本）

### 4. 大运流年 = 行情信号（"人生K线"硬核版）
- 大运 = 十年主浪；流年 = 年 K 线；流月 = 月 K 线；流日 = 日 K 线。
- **逢冲而动**：流年 / 流月冲了命局财库或日支（如丑库遇未年）= 地动山摇，往往是买卖 /
  换工作 / 搬家的时机，敢在底部布局。
- **逢合而守**：被合住动不了 = 这一年少折腾，把资金归拢到最安全的地方。
- **墓库之年** = 收官，落袋为安。
- **调候用神** = 当前最该补的"资产 / 能力缺口"（如喜木火 → 配成长股 + 主动出击类输出）。

> 曾仕强"知命不认命，以德行改运"、认识论八字观"趋势概率 + 结合现实校准"、蚕子"知天命尽人事"
> 这三个大佬观点，在这里统一收敛成一句话：**盘是检查工具，不是算命结论；看完报告，
> 调仓和决策是你自己的事。**

**本 Skill 一句话定位**：不替你算命，给你一份人生财报 + 一张行情提醒条（大运到流日）+ 一张
天时地利人和地图，调仓权永远在你手上。

## 多视角熔接（补充透镜 · 不篡改盘面 · 不破核心逻辑）

> 这一段是「怎么把同一份盘面讲得更立体」的**解读透镜**，不是另一套算法。盘面数据完全不变，
> 上面「财管 / K线」仍是最底层主逻辑；下面这些视角只在**引导措辞**上做补充，帮你从不同圈子
> 的人都能秒懂。**专业 / 学科视角的完整底座见 `major-library.md`（12 学科门类 200+ 专业映射）。**

### 视角 A · 心理学 / MBTI：出厂设定 vs 操作系统（来源：AskLingxi、Nova Masters 对比研究）
两套系统是"不同棱镜"——八字给**出厂设定 + 时间轴**，MBTI 给**当下操作系统 / 仪表盘**：
- 八字"喜忌用神" ≈ MBTI"劣势功能发展"：你最该补的能力，往往就是最不擅长那块（喜印 = 该练
  深度内化，对应 Se 主导者该发展 Ni）。
- 八字"大运流年" ≈ "当下你该动还是该守"：同一命格在不同时间节点际遇天差地别，MBTI 不解释时间。
- 引导写法：对 I 型人说"这个月宜开拓社交 = 去深度一对一交流"，对 E 型人说"去大场面"——
  **把流年建议落到他的操作系统上**。

### 视角 B · 历史学：曾国藩 / 胡雪岩的治家用人 ≈ 命理配置（来源：曾国藩 / 胡雪岩处世绝学）
两位是"为官须看曾国藩，为商必读胡雪岩"的标杆，他们的绝学和命理配置几乎一一对得上：
- 曾国藩"**借人成事 / 以退为进 / 中和**" = 身弱喜**印比**——别 solo 硬扛，找团队 / 导师托底，
  羽翼未丰时"龙蛇屈伸"先守。
- 胡雪岩"**谋而后定 / 有胆有识 / 寻机运机**" = 身强**逢冲而动**——看准流年冲财库就敢在底部布局，
  但前提是"谋深虑远"而非盲动。
- 引导写法：遇到身弱盘，引一句"曾国藩借梯登高"，比干说"你该找团队"有分量十倍。

### 视角 C · 社会学：圈层 / 人脉资本 ≈ 印比 / 比劫（来源：社会资本理论 + 作者人脉资产化实践）
- **印** = 弱关系 / 贵人资本（导师、学长、平台给你的"信用背书"）；**比劫** = 同辈竞争 /
  合作网络（同学圈既是助力也是分流）。
- 引导写法：对创业队友说"你劫财透干 = 合作来钱也来分流，签协议就是穿盔甲"，把玄学词翻译成
  他听得懂的"合伙治理"。

### 视角 D · 产品 / 游戏化（可选轻壳 · 不稀释技术感）
命盘可当一张**角色面板**：日主 = 职业定位、五行 = 五维属性、十神 = 技能卡、流月流日 = 每日
副本门卡。适合迎新摆摊时做成"抽卡式"破冰——但内核仍是上面的硬核财管逻辑，不滑向纯娱乐。

### 视角 E · 经济学 / 金融：风险偏好 ≈ 旺衰，资产配置 ≈ 五行
- 身强身弱 = 风险偏好（仓位）；五行缺旺 = 资产结构失衡；十神 = 现金流结构（正财=工资、偏财=投资、
  食伤=经营变现）。直接用「投资组合再平衡」话术讲，金融/财管人秒懂。
- 引导写法：对财管生说"你缺金=组合里稳健生息资产为空，补一仓债基/考证运（加印）就平衡"。

### 视角 F · 教育学：学习风格 ≈ 印星类型
- 正印 = 体系化吸收（啃教材/跟老师），偏印 = 自学+冷门深挖（B 站/论文），食伤 = 输出倒逼输入
  （教别人/做项目）。帮学生选"怎么学"比"学什么"更准。

### 视角 G · 脑科学 / 认知：注意力 ≈ 五行旺相
- 五行旺 = 默认-mode 强项（天生耗能少的方向），五行缺 = 需刻意练习的弱项；流年冲 = 认知窗口期
  （适合啃硬骨头）。用"注意力预算"替代"运势"，科学党不吃玄学这套。

### 视角 H · 传播学 / 新媒体：伤官配印 = 内容方法论
- 伤官（表达/创新）+ 印（底蕴）= "有想法的创作者"；偏财（流量）= 分发。帮自媒体人把盘面翻成
  "选题-人设-变现"漏斗，比讲"你适合做博主"具体十倍。

### 视角 I · 法学：规则成本 ≈ 官杀，合同 ≈ 穿盔甲
- 正官/七杀 = 规则与制度成本（考公/合规天然适配）；劫财透 = 合伙必有协议（穿盔甲）。法学生/法务
  直接套"规则-风险"框架。

### 视角 J · 设计学：木火 = 审美表达区
- 服装/视觉/产品/数字媒体均属木火（生长+曝光），伤官食神底色 = 才华表达型。江服设计生直接套
  "你的旺势区在哪"，比空谈"你有天赋"落地。

### 视角 K · 组织行为学：团队角色 ≈ 十神分工
- 印比=支持型（托底）、食伤=产出型（变现）、官杀=管控型（标准）、财=资源型。帮创业团队做角色
  分配，玄学词翻译为 RACI。

### 视角 L · 数据科学：盘面 = 一张特征表
- 四柱+五行+十神 = 结构化特征；旺衰 score = 综合评分；流年=时间序列信号。数据人直接当一张
  DataFrame 看，反而最不吃"玄"这套。

### 视角 M · 体育 / 医学：印比=恢复、七杀=极限训练
- 身弱宜印比（恢复/组队训练），身强七杀宜冲（突破极限）；中医"虚则补之"≈"身弱加印"。运动康复/
  中医人秒懂。

> 以上 13 个视角（A–M）是透镜骨架；**专业 / 学科 → 十神 / 五行 / 职业方向 的完整映射表在
> `major-library.md`**，按用户专业直接调对应透镜即可。

## 人物 / 人群画像视角（不同背景用户怎么用 · 不破核心逻辑）

> 同一份盘面，对不同的人价值点不同。下面四类是「引导时该侧重哪块」的模板，盘面照算不误。

### 画像 1 · 江服大一新生（迷茫型）
- 痛点：不知道该冲社团还是先卷绩点。
- 侧重：**旺衰定调性**（身强→先定赛道再冲；身弱→找带你的学长 / 导师）+ **五行喜忌**配精力
  + **地利**（留江西/往东南）。
- 交付："你是乙木偏旺自带发动机，但比劫多易内耗——这学期挑一个表达类输出（加仓火）就够，
  别社团撒胡椒面；籍贯江西属火地，留本地或往杭州厦门都顺。"

### 画像 2 · 考公 / 考研党（规划型）
- 痛点：什么时候该全力冲、什么时候该蓄力。
- 侧重：**大运流年行情**（逢冲之年宜动不宜守、墓库之年宜落袋）+ **官杀 = 规则成本** + **时代**
  （当下火运对文化/体制赛道 Beta）。
- 交付："你这步大运官杀透干 = 制度内赛道适配，但流年逢合先别乱换方向；把考公当定投，别赌单年；
  火运期文化/体制类有时代 Beta，顺势但不躺。"

### 画像 3 · 创业 / 商赛队友（资源型）
- 痛点：分工、合伙、谁扛风险。
- 侧重：**十神现金流**（劫财 = 合作分流要穿盔甲、食伤 = 谁负责变现）+ **印比 = 团队红利** + **人和**。
- 交付："你食伤生财旺 = 你适合对外变现（路演 / 谈客户）；队友劫财重 = 分工写清别让蛋糕被分；
  你说过带团队踩过坑 = 正应穿盔甲，这次股权写死。"

### 画像 4 · 校友社交破冰（连接型）
- 痛点：迎新摆摊怎么让人记住、愿意聊。
- 侧重：**流月流日当日行情**（合局=今天适合协作破冰）+ 游戏化角色面板轻壳 + **地利**（同乡牌）。
- 交付："今天流日三合你的日支 = 天然适合跟人深聊，摆摊别干坐，主动拉人抽张『出厂财报』；
  同省的直接打『老乡+五行』牌，破冰最快。"

### 画像 5 · 银发 / 退休长辈（传承型 · 降财管隐喻权重）
- 痛点：不关心K线，关心身体、家庭、含饴弄孙、别被割。
- 侧重：**土重的稳**（压舱石 = 经验值钱，但别固执钻牛角尖）+ **水润防孤** + 提醒"墓库年守成"。
- 交付：少讲仓位，多讲"您阅历是全家印星，带带晚辈就是加印；流年冲了别冲动投资，守成最稳"。

## 使用指南（傻瓜版 · 问答模式 + 三步出盘）

> 目标：零基础也能在 5 分钟内排出一个盘，并通过问答拿到针对性引导（含天时地利人和）。

### 前置（一次性）
1. 装 Node.js（≥ 18 即可，官网下 LTS 版下一步到底）。
2. 打开终端（Windows 用 PowerShell / Git Bash），进到 `calculator` 目录：
   ```bash
   cd calculator
   npm install        # 装依赖（lunar-typescript），首次跑要等几十秒
   ```

### 模式 A · 本地问答（推荐，最完整）
1. 先和用户聊（按「引导式问答 intake」多轮深问：身份/生辰/出生地(到镇)/家庭环境/经历；单轮 agent 则发一次性问卷）。
2. 拿到生辰后排盘：
   ```bash
   node dist/run-chart.js --year=2005 --month=3 --day=12 --hour=8 --minute=30 --gender=male --ref-date=2026-08-29 > chart.json
   ```
3. 转文本 + 把 intake 回答一起喂给 AI：
   ```bash
   node dist/dump-text.js --input=chart.json
   ```
   把输出 + 用户回答复制给任意 AI（或本 Skill 内调用），AI 按「解读框架」产出针对性方案
   （含天时地利人和三维结论）。

### 模式 B · 纯提示词降级（无 node 环境时）
若运行环境不能执行 node（如某些平台只加载 SKILL.md 当提示词）：
- 让用户提供生辰，AI 按「职业底色库 + 核心逻辑 + 天时地利人和框架」做**轻量口头排盘**
  （日主/五行/十神靠规则估算，**精度降级，明确告知用户"这是简化版，非引擎精准盘"**）。
- 地利/时代维度仍可用：地利查内置「地支方位五行原型表」、时代查内置「九运时代原型表」，**不依赖 node**。
- 引擎仍是金标准；降级只为"没环境也能聊"。

### 参数说明
- `--year/month/day/hour/minute`：出生阳历年月日时（**hour 用 24 小时制**，23 点后按次日日柱）。
- `--gender`：`male` 或 `female`（影响大运顺逆）。
- `--ref-date`：**参照日**，算流年流月流日用，不传默认今天。想看"某年某月行情"就传那天。

### 常见问题（FAQ）
| 问题 | 答 |
|---|---|
| 不知道具体时辰（只知早晚）？ | 按"早=6点 / 中=12点 / 晚=18点 / 夜=23点"估一个；时柱影响小，大架构不变。 |
| 农历生日怎么填？ | 直接填农历对应的阳历日期即可（盘按节气走，填阳历最稳）。 |
| 23 点后出生？ | 引擎已按"夜子时次日派"处理（日柱跳次日），和你档案一致，不用手动改。 |

## 解读框架（AI 执行流程 · Skill 被调用时现跑）

AI 拿到 `dump-text.js` 的补层文本 + 用户 intake 回答后，按下面 7 步产出第二段引导
（可叠加上面任一视角 / 职业底色）：

0. **走 intake**：先按「引导式问答 intake」问全维度（身份/生辰/出生地(具体到镇)/家庭环境/经历），拿到用户自述
   （没问就先聊，别直接吐模板）。人和维度只取当轮自述。
1. **抽骨架**：日主 + 格局（商业模式）+ 旺衰（score 与判定 = 能攻还是该守）+ 调候用神
   （该补的缺口）+ 五行缺旺（组合失衡在哪类）。
2. **定调性（风险偏好）**：
   - 身旺 → "你自带发动机，能主动出击，但别一把梭——先定赛道再下注。"
   - 身弱 → "你吃平台和团队红利，适合定投式积累，别 solo 硬扛。"
   - 中和 → "你弹性大，看大运流年借势，别跟自己较劲。"
3. **拉职业底色**：根据用户身份调「职业底色库」对应块（CPA/软件/公务员/教师/销售/设计/医护…），
   把盘面翻译成他听得懂的操盘语言（例：对程序员讲"技术三角 印+食伤+官杀"，对 CPA 讲
   "正印考证运+财库把关人"）。
4. **拉流年流月流日（当下行情）**：看参照日当下——流年 / 流月 / 流日透出什么十神、冲了
   命局哪个支 / 宫。例："流日乙亥合你时干庚、三合月日（亥卯未），今天适合跟同辈协作推进
   （合局 = 持仓待涨），别单打。" → 把 decade 级趋势落到"这月 / 这周 / 今天该攻还是该守"。
5. **叠天时地利人和（三维合成）**：
   - **天时**：出生盘结论 + 时代盘（有 web 搜当年行业 Beta；无 web 用内置九运表，标明"通用原型非实时"）。
   - **地利**：用户所在地 → 查内置「地支方位五行原型表」+ 喜用神，给"宜留/宜去"方位建议。
   - **人和**：把用户自述经历映射十神/宫位，钉到具体人。
   - 产出"三维结论一句话"（何时/何地/联合谁/做啥）。
6. **熔案例 + 视角**：引用大佬 / 历史一句（曾仕强"知命不认命" / 曾国藩"借人成事" /
   认识论"趋势概率"三选一贴合的）+ 一个脱敏案例类比（`examples/index.md` 示例库 或同类）+ 必要时叠心理学 /
   社会学视角（视角 A / C），**不点他人真名**。
7. **给行动（调仓建议）**：3 条校园/职业生活化配置建议，每条回扣"尽人事"——格式如
   "喜火 → 这学期去试一次演讲 / 商赛（加仓火），把那面练出来"。
8. **收口 + 显式标识**：末句带"趣味文化体验，人生财报+天时地利人和地图而已，调仓决策你自己拿"，并在末尾固定追加「边界（合规红线）」里的 AI 生成标识 footer（⚠️ 本内容为 AI 生成…仅供娱乐参考）。

**语气**：平调、直接、不装神弄鬼；就像平常朋友聊天的口吻，绝不说"你命里注定"。

## 可行性评估（专业视角 · 哪些做、哪些不做）

### ✅ 能做的（核心护城河）
1. **精准排盘引擎**：自研 + 节气校正 + 晚子时次日派 + 流年流月流日，盘面可复现——这是底色，别人抄不走。
2. **财管 / K线隐喻**：用真财管框架解构八字，市面独一份（"人生K线"是 AI 画皮，你是真骨架）。
3. **多视角熔接**：心理 MBTI / 历史曾胡 / 社会学人脉 / 游戏化——不同圈子秒懂。
4. **引导式问答 intake**：先问后解，从"通用模板"升级"个性化方案"，这是体验跃迁。
5. **职业底色库**：用公开职业—十神/五行框架，覆盖 CPA/软件/公务员/教师/销售/设计/医护/学生/

8. **联网搜索能力声明式接入（本次新增）**：有 web 就拉实时宏观/行业/地理，无 web 用内置九运/
   方位表，跨智能体通吃（见「运行环境适配」）。

### ⚠️ 不能做 / 必须守的（边界）

5. **准确性定位**：八字是经验文化框架，非科学验证。必须标"趣味/文化体验"，不宣称"准"。
6. **技术隐喻别滑向纯娱乐**：游戏化(角色面板)只能是轻壳，内核硬核财管逻辑不能丢——丢了就

## 运行环境适配（多智能体 · 能力分级）

> 用户要求适配主流智能体（WorkBuddy/Trae/Codex/国产）。设计原则：**SKILL.md 是方法论提示词
> （任何 agent 可加载），calculator/ 是 node 引擎（仅能跑 node 的环境可用）；联网搜索写成

| 仅加载 SKILL.md、无 web | ❌ | ❌ | 用内置九运/方位表 + 示例盘讲解 | **Tier D** |

- **对话模式适配（针对"有些 agent 不能多轮"）**：本 Skill 的 intake 设计成双模式——

- **联网搜索能力声明式**：有 web 拉实时背景、无 web 用内置九运/方位表，跨智能体通吃

  - 格局立格：纯气月支直接立格、四生四库看透干、比劫按建禄 / 月刃
- **可调参**：阈值与权重集中在 `calculator/bazi-enrich/`，可按流派微调
- **解读可迁移**：财管隐喻 + 多视角 + 职业底色 + 问答 intake + 天时地利人和写在 SKILL.md，
  换学校 / 换场景改锚点即可复用

## 常见问题 FAQ

**Q: 必须装 node 吗？**
A: 想要精准盘面就装（`dist/` 已预编译，`npm install` 后 `node dist/run-chart.js ...` 即可）。没 node 也能用，AI 走「纯提示词降级档」按描述给方向，精度降一档。

**Q: 输入会不会被存下来？**
A: 不会。单次会话无状态，不跨会话记忆，不读你私人文件。

**Q: 八字准不准？**
A: 文化框架，不是科学。参考十神结构 + 喜忌方向，别当判决书。

**Q: 江服新生怎么用？**
A: 给出生辰 + 出生地（具体到镇） + 父母职业大致方向 + 经历 1-2 件，AI 走「天时地利人和」三维给你平调建议。迎新摆摊直接搬 `examples/index.md` 的 5 个示例对话。

**Q: 出错了怎么办？**
A: 复述输入 + 报错提示，AI 会按上面「错误处理」表重试或降级。

**Q: 能用作比赛材料吗？**
A: 可以。MIT 开源，记得标原作者 + 链接 GitHub repo。

**Q: 怎么挑职业 / 专业？**
A: 详见 `profession-library.md`（300+ 职业，按国家职业大典 8 大类）和 `major-library.md`（12 学科门类 200+ 专业）。同一份盘用对应职业的操盘语言讲，对方秒懂。

**Q: 13 门学科透镜从哪来？**
A: 心理学（MBTI）/ 历史学 / 社会学 / 游戏化 + 经济学金融 / 教育学 / 脑科学 / 传播学 / 法学 / 设计学 / 组织行为学 / 数据科学 / 体育医学。详见 SKILL.md「多视角熔接」段。

```bash
cd calculator && node validate-crosscheck.js
```

|---|---|---|
| **日柱** | JDN（儒略日）天文算法 | `干支序号 = (JDN + 49) mod 60`。常数 49 由 1949-10-01（甲子日）与 2000-01-01（戊午日）两个互不相关的历史锚点交叉确认 |
| **月干** | 《五虎遁》年上起月 | 甲己丙作首、乙庚戊为头、丙辛寻庚起、丁壬壬位流、戊癸甲好求 |
| **时干** | 《五鼠遁》日上起时 | 甲己还加甲、乙庚丙作初、丙辛从戊起、丁壬庚子居、戊癸壬子途 |
