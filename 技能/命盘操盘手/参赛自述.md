## 一、它到底是什么（先讲主线，命理当隐喻）

把「生辰八字」读成一份 **人生财务体检报告**——

- 五行 = 五类资产（资产配置）
- 身强身弱 = 你的风险偏好 / 仓位（能攻还是该守）
- 十神 = 现金流结构（你靠什么进钱、靠什么耗钱）
- 大运流年 = 行情信号（这月 / 今年该加仓还是防守）

盘是「帮你认识自己的诊断单」，**不是判决书**。怎么读，由 AI 套一套财管语言给你——
说清你该在何时、何地、联合谁、做啥。

**所以它本质是「财商启蒙 + 自我探索」**，八字只是年轻人好接的传统文化外壳。
江服新生刚入学，最该想的是「我是啥底子、该往哪使劲」——这工具用他们熟悉的语言把这个事讲明白。

## 二、为什么合规（逐条对照 2025 监管红线）

| 监管红线 | 本作品做法 | 结果 |
|---|---|---|
| 禁"八字定终身 / 天命不可改"宿命话术 | 盘=诊断单非判决书；不替人定职业；收口必带"决策你自己拿" | ✅ |
| 禁诱导付费 / 破灾改运 / 开光高价饰品 | MIT 免费开源；无任何付费、改运、开光、饰品 | ✅ |
| 禁采集身份证 / 家庭隐私 | 只收生辰（年月日时+性别）+ 可选所在地/行业，不强制、不存储 | ✅ |
| 禁向未成年人推付费命理 | 面向成年大学生群体；免费、无付费推送 | ✅ |
| AI 生成内容显式标识 | 每次输出末尾固定 footer：「⚠️ 本内容为 AI 基于传统文化框架生成，仅供娱乐与自我探索参考，不构成决策依据」 | ✅ |

**额外护城河**（源码可查）：
- SKILL.md 设「边界（合规红线）」7 条 +「隐私 & 合规」段，AI 被调用时强制走红线；
- **单次会话无状态**：不存储、不跨会话记忆用户说了啥，不读任何私人文件；
- 所有示例盘均为虚构 / 脱敏演示，**全库零真实生辰**（含作者本人）；
- 大赛平台规则第 3 条（禁诱导外链 / 恶意代码）、第 4 条（禁提他人隐私）均满足：无外链、无真人数据。

> 结论：本作品属「传统文化娱乐 + 自我探索」范畴，非网络封建迷信，已落全合规护城河。

## 四、评委引导话术（建议你这么读它）

1. 打开 `showcase.html`——先看盘面长啥样（虚构示例盘，带显式标识）；
2. 翻 `examples/index.md`——5 个江服新生 / 考公 / 自媒体 / 程序员 / 高考志愿的真实跑通对话，看它怎么把"命理黑话"翻成大白话 + 操盘比喻；
3. 看 `profession-library.md` / `major-library.md`——职业 / 专业覆盖厚度；
4. 读 `SKILL.md` 的「边界（合规红线）」——合规不是嘴上说说，是写进 prompt 强制执行的。

**一句话收尾**：它不是来"算你命"的，是来帮江服新生用熟悉的语言，想清楚"我是啥底子、该往哪使劲"的。
