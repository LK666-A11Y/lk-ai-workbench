# 示例库（小白直接读 · 5 个完整跑通对话）

> 这 5 条是给**完全没接触过命理/财管**的人看的示范：从「人设」到「出厂财报」到「年度行情」到「三维结论」到「AI 引导话术」，一条龙跑通。
> 全部为**虚构示例盘**（出生盘由 `calculator/` 引擎真实产出），不对应任何人；对话为「命盘操盘手」平调引导风格，绝不说"你命里注定"。
> 原始引擎 JSON 见每条末尾链接，可自行打开核对盘面（透明、可复现）。
>
> 想直接套用：找一个跟你背景最接近的人设，把生辰换成你自己的，按同样结构走一遍即可。

## 示例 1 · 江服大一新生破冰（社团选择纠结）

**人设（虚构）**：小林，公历 2007-09-15 14:00 生，江西赣中某县人，江服大一新生。开学两周，不知道该冲社团还是先卷绩点，怕选错浪费时间。

**出厂财报（引擎直出）**
| 项 | 值 |
|---|---|
| 四柱 | 丁亥 己酉 壬子 丁未 |
| 日主 | 壬水 |
| 格局 | 正印格（月支酉本气辛=正印） |
| 旺衰 | 偏旺（score 3.5，信心低） |
| 调候用神 | 甲、庚 |
| 五行 | 水3 金1 火2 土2 木0（**缺木**）；旺相：金旺·水相·木死 |
| 十神底色 | 比劫3 财2 官杀2 印1 食伤0 |

**年度行情（参照 2026-08-29）**
- 流年丙午（偏财）：六冲你的日支子、六合时支未 → 今年"机会/钱"在动，但也容易分心。
- 流月丙申（偏财）：拱辰（合你日支）、害年支亥 → 这个月适合小步试水，别一下铺太大。
- 流日乙亥（伤官）：拱卯、拱丑 → 今天适合动笔/动嘴表达，别闷着。

**三维结论**
- 天时：正印格 + 偏旺，吃学习/平台红利，但**比劫多**（同辈竞争/内耗），**缺木**（表达输出弱）。
- 地利：江西属火地（财），留本地读书顺；往东（木）杭州/上海类城市也顺你喜木。
- 人和：你自述"想冲又怕选错" = 典型比劫内耗，正该找个带你的学长（加印）定锚。

**AI 引导（平调版）**
你是壬水偏旺，自带发动机，但比劫多——组合里"同辈"这一票太重，容易在社团里撒胡椒面、互相耗。
正印格说明你吃平台和学习的红利，证书/课程一上手就顺；但缺木（食伤）= 表达输出那面弱，得主动练。
这学期别贪多：挑一个"要你产出"的社团（新媒体/商赛/演讲类，属木=加仓表达），把那面练出来就够。
喜木金 → 木是表达、金是钻研，留江西或往杭州都顺；流年偏财在动，九月可以小试一个比赛，但别一下投三四个。
调仓是你自己的事，我给你地图，路你自己走。

## 示例 2 · 考公党（第几年冲、该动还是该守）

**人设（虚构）**：阿强，公历 2004-11-03 10:00 生，男，江西人，在职备考，今年是第 2 年冲国考，纠结"今年该全力冲还是先蓄力"。

**出厂财报（引擎直出）**
| 项 | 值 |
|---|---|
| 四柱 | 甲申 甲戌 丙戌 癸巳 |
| 日主 | 丙火 |
| 格局 | 食神格（月支戌本气戊=食神）；时干癸水正官透 = 官星有力 |
| 旺衰 | 偏弱（score -2.6，信心低） |
| 调候用神 | 甲、壬 |
| 五行 | 木2 火2 土2 金1 水1（无缺）；旺相：土旺·火休·水死 |
| 十神底色 | 印2 比劫2 食伤2 财1 官杀1 |

**年度行情（参照 2026-08-29）**
- 流年丙午（比肩）：拱寅（合月/日支）、拱未（合时支） → 今年同辈/搭子气场强，适合组队备考、找搭子互相盯。
- 流月丙申（比肩）：六合时支巳、相刑年+时支申 → 这个月有"比着学"的劲，但别陷入无效比较内耗。
- 流日乙亥（正印）：六害年支申、六冲时支巳 → 今天适合静下来啃书（加印），别被杂事冲散。

**三维结论**
- 天时：偏弱 + 正官透 = **制度内赛道天然适配，但本金（自身能量）不足**，得靠印比（考证/报班/带你的学长）托底。
- 地利：考公留江西 = 主场近、江西岗多，务实优先；方位别纠结，喜木水（东/北）平时多往图书馆/自习室（印地）钻。
- 人和：你自述"第 2 年冲" = 定投心态对了；偏弱别赌单年，把考公当按月定投。

**AI 引导（平调版）**
你是丙火偏弱、正官透干——官杀（规则/压力）是你的主场，体制内赛道天生适配；但身弱像本金不足，得用印比做安全垫才扛得住。
把考公当定投，别赌单年：流年比肩（同辈）在动，今年适合找个搭子互相盯进度，比一个人闷头强。
身弱别 solo 硬扛，报个班/找带你的学长 = 加印；羽翼未丰先守（曾国藩借梯登高那个意思）。
逢冲之年（冲官杀/日支）才宜动（报考/调动），今年流年拱合为主，先把底子打厚，别急着乱换方向。
上不上岸你自己冲，我给你行情条，不替你下注。

| 旺衰 | 中和（score 2.0，信心中） |
| 调候用神 | 癸、丙 |
| 五行 | 木2 火2 土1 金1 水2（无缺）；旺相：火旺·水囚·金死 |
| 十神底色 | 比劫2 食伤2 财1 官杀1 印2 |

**年度行情（参照 2026-08-29）**

- 流月丙申（伤官）：六害日支亥、三会年+时支申 → 这个月适合把一条内容做深，别同时开三个号。
- 流日乙亥（比肩）：无特殊冲合 → 今天适合找同频搭子聊选题，平推就行。

**三维结论**

- 人和：你自述"怕露脸" = 伤官见官无财时的小怂，正常；先从小红书图文（食伤轻量）试，再过渡口播。

**AI 引导（平调版）**

怕露脸就从图文起步，等食伤（表达）练顺了再上口播；调仓是你自己的，我给你出厂财报，号你自己起。

## 示例 4 · 程序员（后端工程师的职业语言）

**人设（虚构）**：老陈，公历 2002-01-18 09:00 生，男，后端工程师，工作 3 年，纠结"该往架构/算法深钻，还是转管理/产品"。

**出厂财报（引擎直出）**
| 项 | 值 |
|---|---|
| 四柱 | 辛巳 辛丑 丙戌 癸巳 |
| 日主 | 丙火 |
| 格局 | 正官格（月支丑藏癸透干=正官）；年/月干辛金正财双现 |
| 旺衰 | 偏弱（score -5.0，信心高） |
| 调候用神 | 壬、甲 |
| 五行 | 火3 土2 金2 水1 木0（**缺木**）；旺相：土旺·火休·木囚 |
| 十神底色 | 比劫3 食伤2 财2 官杀1 印0 |

**年度行情（参照 2026-08-29）**
- 流年丙午（比肩）：六害月支丑、拱寅（合日支）、拱未（合时支） → 今年同辈/团队气场强，适合借团队成长。
- 流月丙申（比肩）：六合年支巳、相刑年+时支申 → 这个月适合啃技术硬骨头，但别钻牛角尖。
- 流日乙亥（正印）：六冲年+时支巳 → 今天适合看源码/补底层（加印），冲掉浮躁正好沉下心。

**三维结论**
- 天时：正官格 + 财（辛金）旺 + 偏弱 = 技术三角里"做（食伤）+ 逻辑精密（财/金）+ 标准（官）"都有，但**印（木/底层钻研）缺**，得靠自学补。
- 地利：程序员属金火，你喜水木（北/东），平时多泡技术社区/开源（印地）补底层。
- 人和：你自述"纠结深钻还是转管理" = 印缺时的典型迷茫；比劫3 说明你吃团队红利，偏弱别 solo。

**AI 引导（平调版）**
你是丙火偏弱、正官格、辛金正财双透——财（金=逻辑/数字/规则）旺说明你底子精密，正官（标准/攻关）透说明你能扛标准线，是典型"技术产出型"。
但印（木=底层钻研/学习库）为 0，等于技术三角缺一条腿：别只做 CRUD，往架构/算法（加印/木）深，定期学新框架防"枭神夺食"（钻旧技术不学新东西）。
偏弱 + 比劫3 = 你吃团队红利，别 solo 硬扛，借团队成长最快；流日正印在动，今天适合沉下心看源码。
想转管理也行，那是"食伤生财"线（把技术变成带人/产品），但先把印这条腿补上再转，不然空架子。
路你自己选，我给你技术财报。

## 示例 5 · 高考志愿（财管 vs 服装设计 vs 计算机 怎么选）

**人设（虚构）**：学妹，公历 2008-03-08 09:00 生，女，高三，分数够江服，纠结报**财务管理 / 服装设计 / 计算机** 哪个，家长想让她学财管"好就业"。

**出厂财报（引擎直出）**
| 项 | 值 |
|---|---|
| 四柱 | 戊子 乙卯 丁未 乙巳 |
| 日主 | 丁火 |
| 格局 | 偏印格（月支卯本气乙=偏印，双透） |
| 旺衰 | 偏旺（score 6.0，信心高） |
| 调候用神 | 庚、甲 |
| 五行 | 木3 火2 土2 金0 水1（**缺金**）；旺相：木旺·火相·金囚 |
| 十神底色 | 印3 比劫2 食伤2 财0 官杀1 |

**年度行情（参照 2026-08-29）**
- 流年丙午（劫财）：六冲年支子、六合日支未、三会日+时支午 → 今年"同辈/自我主张"气场极强，适合自己拿主意。
- 流月丙申（劫财）：六合时支巳、相刑时支申 → 这个月容易跟人（包括家长）意见撞，别吵，列清单比。
- 流日乙亥（偏印）：六冲时支巳、三合月+日支亥 → 今天适合一个人静下来翻专业资料（加印）。

**三维结论**
- 天时：偏印格 + 偏旺 + **印3 缺金（财0）** = 钻研/学术底子厚，但"务实落地/钱"那面弱，典型"想多做少"组合。
- 地利：木火旺 = 服装设计/视觉/文教（木火类）是她顺风顺水的区；金（财管/金融/计算机逻辑）是她缺的，补上更平衡但不算舒适区。
- 人和：你自述"家长让学财管" = 外部声音压过自我主张；流年劫财在动，今年正该自己拿主意。

**AI 引导（平调版）**
你是丁火偏旺、偏印格、印（木）三重——你天生是"钻研型/学者底"，吃深度学习和专业壁垒的红利，适合木火类（服装设计/视觉/文教/研究）。
但财（金）为 0，等于组合里"务实落地/搞钱"那块空着：财管、金融、计算机逻辑都属金，是你缺的，不是你最舒服的区，但补上能让组合更平衡、不至于想多做少。
三个选项摊开看：
- 服装设计（木火）= 顺你旺势，上手快、有表达空间，但家长担心的"就业宽不宽"得自己用作品说话；
- 财务管理（金）= 补你缺的金，落地性强，但你要主动加印（考证/实习）才不枯燥；
- 计算机（金火）= 折中，逻辑（金）你缺但火（你旺）能扛，适合愿意补底层的人。
我的地图：想稳扎顺手→服装设计；想逼自己补落地能力→财管；别三个都报贪。最终志愿你自己填，我不替你圈。
