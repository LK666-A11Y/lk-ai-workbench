## 🧭 六条工作原则

从我 4 个月的实践里提炼的，不是抄来的：

1. **先定骨架再填肉** — 命名规则、编号体系、层级深浅、双链规范，四件事定死再动笔
2. **不碰撞不落地** — 任何结论必须与「大佬做法 / 行业趋势 / 我的实际」三视角交叉验证
3. **事实必须带来源** — 履历性信息标注来源，引用超过 3 次必回源核对
4. **截止日 ≠ 已完成** — 只有亲述才算完成，状态三态标注
5. **大文件走专线** — Git 只存文本，媒体走 IMA / 网盘
6. **70/30 自主** — AI 扛 70%，人做 30% 的判断与拍板
