# PDF文字提取乱码

> 创建时间：2026-05-26

## 踩坑场景

用 PyMuPDF 提取美的集团 ESG 报告（79 页 PDF）的文字，结果 70% 的页面是 `•` 和 `⚫`，完全不可读。

## 原因

现代企业发布的正式 PDF（ESG 报告、年报、合同等）大量使用**信息图表、设计排版**，文字嵌在图片里，不是纯文本层。PyMuPDF 的文字提取只能抓到文本层的碎片（页码、项目符号），核心内容全丢。

## 解决方案

```
PDF → PyMuPDF 提取页面为 PNG → 千问 VL 看图 → 返回文字描述
```

具体步骤：
1. `fitz.open()` 打开 PDF
2. `page.get_pixmap(dpi=150)` 逐页渲染为图片
3. 调用视觉翻译桥（千问 VL API）「看图说话」
4. 拿到完整文字描述，继续干活或记笔记

## 适用判断

| PDF 类型 | 用什么 |
|----------|--------|
| Word 导出/纯文本 PDF | PyMuPDF 文字提取就够了 |
| 设计排版/图片式 PDF | 转 PNG → 千问 VL |
| 禁止下载的网页文档 | GoFullPage 截全页 → 同上 |

## 成本

千问 VL 每页约 2500 tokens，约 0.01 元/页。79 页全看约 0.8 元。
