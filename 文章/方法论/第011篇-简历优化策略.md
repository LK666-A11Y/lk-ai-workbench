# 简历优化策略

> 创建时间：2026-05-26

> 不是造假，是把做过的事用商业语言讲出来。

## 核心原则

| 原则 | 说明 |
|------|------|
| STAR 法 | 背景 → 动作 → 结果，每个项目都讲清楚"做了什么、带来了什么" |
| 量化优先 | 能写数字不写形容词。"分析了很多数据" → "10万+订单，9张数据表" |
| 业务导向 | 技术是手段，业务是目的。SQL/Power BI 是工具，降运费才是价值 |
| 相关性过滤 | 去什么岗位放什么内容。财务岗放 C1 驾照无所谓，数据分析岗删掉 |

## 本次优化（2026-05-25）

### 做了什么
1. **项目经历从 6 条压缩到 4 条**：把技术细节（安装 tqdm、配置编码）合并进业务操作，每条都有"动作 + 结果"
2. **新增自我评价**：3 句话覆盖核心竞争力——数据+AI 全链路、队长领导力、跨境电商实践
3. **AI 技能具体化**：从"会用 AI 工具"改成"用 Claude Code + DeepSeek 搭建自动化分析流水线，一键生成 Excel+Word+PPT+图表"
4. **删除 C1 驾照**：跟数据分析无关，占地方
5. **补充真实联系方式**：手机、邮箱、GitHub

### 为什么这样改
- HR 看简历平均 6-10 秒，6 条子弹=2 秒/条，来不及读完
- 4 条子弹 + 每条一个有分量的数字 = 扫过去就能抓到重点
- 自我评价不是"我勤奋好学"，是"我有什么证据证明我能干活"

## 跟 AI 配合的长期策略

claude.md + obsidian 知识库 = 你的简历永远是最新版本：
- 做完新项目 → obsidian 自动记录 → 简历同步更新
- 投不同岗位 → 调取不同项目经验 → 针对性投递
- 面试前 → AI 根据简历生成可能被问到的问题
