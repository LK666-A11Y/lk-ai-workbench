# AI 提示词框架指南

> 创建时间：2026-05-25

> 一份通用指南，让 AI 听懂人话、输出你想要的结果。

---

## 核心公式：六要素框架

好的提示词 = 把话说清楚，不是堆字数。

| 要素 | 意思 | 不写的后果 |
|------|------|------|
| **角色** | 你是谁、AI 是谁 | AI 瞎猜你的水平 |
| **背景** | 为什么做、什么场景 | 给的建议不贴实际 |
| **任务** | 具体要干什么 | 答非所问 |
| **约束** | 不要什么、限制什么 | AI 放飞自我 |
| **格式** | 输出什么样子 | 结果没法直接用 |
| **示例** | 给个参考（选填） | 风格可能跑偏 |

---

## 从烂到好

| 级别 | 例子 |
|------|------|
| 烂 | "帮我写个方案" |
| 还行 | "帮我想个暑假社会实践方案" |
| 好 | "我是大二财务学生，要去工厂做成本调研。帮我列一份观察提纲，分原材料/人工/制造费用三类，每类5-8个问题" |

## 五个万能模板

### 1. 角色扮演分析
```
你是一个 [领域] 的 [角色]，有 [X] 年经验。
我的情况是：[背景]
请从 [角度] 分析 [问题]，输出 [格式]。
直接说实话，不用鼓励。
```

### 2. 零基础学知识
```
我是一个完全零基础的人，不懂 [领域] 的任何术语。
请用最通俗的比喻解释 [概念]。
每个术语都要用日常生活中的东西来类比。
最后给我一个一句话总结。
```

### 3. 优化已有内容
```
以下是 [一段文本/代码/方案]：
---
[粘贴内容]
---
请从 [角度1] [角度2] [角度3] 三个方向提出优化建议，
每一条要有"改前 → 改后"的对比。
```

### 4. 生成结构化内容
```
帮我生成 [内容类型]，主题是 [主题]。
要求：
1. [要求一]
2. [要求二]
3. [要求三]
输出格式：[表格/列表/分段/代码]
```

### 5. 纠错审查
```
帮我检查以下内容的问题，从 [角度1] [角度2] [角度3] 审查。
---
[粘贴内容]
---
有问题的标注 ⚠️，严重的标注 🔴，给出具体修改建议。
```

## 常见错误

| 错误 | 为什么不行 |
|------|------|
| 一次问太多问题 | AI 会挑着答，不如逐个问清楚 |
| 太抽象 | "帮我分析" ← 分析什么、怎么分析都没说 |
| 不给约束 | AI 给你写2000字，其实你只要300字 |
| 新对话没给背景 | 每次都说一遍才能持续准确 |

---

## 终极原则

> AI 不是人，是工具。需求说清楚了就好用，说不清楚就瞎编。

如果你的场景是固定重复的，写成 `CLAUDE.md` 或系统提示词，写一次永远生效。
