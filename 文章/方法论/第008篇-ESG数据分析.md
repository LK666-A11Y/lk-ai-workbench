# ESG 数据分析

> 创建时间：2026-05-26

> 财务 + 环境数据 + 可视化 = 你已经在做的事，换个赛道而已。

---

## 是什么（小白版）

| 字母 | 意思 | 通俗翻译 |
|------|------|----------|
| E（环境） | 碳排放、能耗、污染 | 工厂排了多少碳、用了多少电 |
| S（社会） | 员工权益、供应链合规 | 工人工资有没有按时发、有没有童工 |
| G（治理） | 反腐败、合规、董事会结构 | 公司有没有做假账、出口报关是否合规 |

本质上就是**把非财务数据量化成财务影响**——排一吨碳要交多少税、绿电省多少钱、ESG 评级降一级股价跌多少。

## 跟你现在的关联

| 你已有的 | ESG 直接复用 |
|----------|-------------|
| SQL 多表关联 | 碳排放表 JOIN 财务表，算碳成本占比 |
| Power BI 仪表盘 | ESG 报告最核心就是可视化——碳趋势、绿电占比、合规仪表盘 |
| 巴西电商利润分析 | 把运费换成碳成本，分析逻辑一模一样 |
| 端对端自动化 | 每月自动出 ESG 月报，跟日报一个配方 |
| 行业调研能力 | EU CSRD 法规、中国三大交易所披露要求 |

**一句话：你不需要学新东西，只需要把现有技能换个应用场景。**

## 为什么值得关注

### 政策驱动（硬需求）
- **欧盟 CSRD**：2024 年起在欧盟有业务的中国企业必须披露 ESG 数据 → 跨境电商全部中招
- **中国三大交易所**：2026 年起强制披露，从央企慢慢覆盖所有上市公司
- **碳关税 CBAM**：出口到欧盟的钢材、铝、化肥等，2026 年起要交碳税

### 薪资
- 应届 ESG 数据分析师：8-15K
- 有经验：20-35K
- 比纯财务高一个台阶，因为既懂财务又懂环境数据的人少

## 学习策略（功利版）

### 不要做的事
- 花钱买 ESG 证书（贵的几万块，对你现在来说 ROI 太低）
- 死磕 GRI 标准全文（几百页，等入职了再看）
- 被卖课的忽悠"ESG 是下一个风口，不学就晚了"

### 要做的事

| 阶段 | 做什么 | 成本 |
|------|--------|------|
| **现在** | 白嫖 PDF → AI 拆解 → 记笔记 → 用巴西数据练手 | 零 |
| **暑假** | 大叔工厂观察：能耗、物流碳足迹、工人情况 | 零 |
| **大三上** | 拿一个免费 ESG 报告框架（GRI/TCFD 摘要）→ 仿写一份 mock ESG 报告 | 零 |
| **大三下** | 如果确定走这条路，考一个性价比高的证书（如 SASB FSA） | ¥2,000-3,000 |

### 白嫖资料的正确姿势

```
微信卖课 PDF 拖给 Claude Code
  → AI 拆解：哪些是干货、哪些是水、哪些是卖课话术
  → 提炼 3-5 条可操作的东西
  → 跟巴西电商数据结合：能不能练手？不能练就跳过
  → 记进 Obsidian，双向链接
```

**核心原则**：看完能练手的才记，纯概念的跳过。

## 暑假工厂观察维度（初步提纲）

| ESG 维度 | 能观察什么 | 能问什么 |
|----------|-----------|---------|
| E-环境 | 原材料是什么（塑料/橡胶/金属）、车间能耗感觉 | "你们用电大概一个月多少？有没有算过每件产品的能耗成本？" |
| E-物流 | 货从哪运到哪、用什么物流 | "出口到欧洲一个柜运费多少？有没有因为环保要求被卡过？" |
| S-社会 | 工人工作环境、排班方式 | "旺季工人加班的工资怎么算的？" |
| G-治理 | 出口报关流程 | "报关有没有遇到过合规问题？" |
