# 论文模板自动化

> 创建时间：2026-05-25

> 老师发模板 → AI 出内容 → 脚本自动套格式 → 交作业

---

## 痛点
老师给模板（有格式要求）+ 题目 → AI 生成内容 → **手动调格式很痛苦**

## 解决思路
1. 拿到老师模板（.docx）
2. 把题目给 DeepSeek/千问 → 生成论文正文
3. Python 脚本读取模板样式 → 自动填入内容
4. 输出符合格式要求的 .docx

## 核心逻辑
Word 模板里的"格式"本质是**样式**（标题1、标题2、正文、页眉页脚）
脚本只需要：读模板 → 识别样式 → 匹配内容 → 套入
