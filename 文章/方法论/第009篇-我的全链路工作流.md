## 全链路（按事分类）

### 链1：数据分析（已跑通）
```
原始数据 → SQLite → SQL分析 → ECharts/Power BI仪表盘 → 白话讲商业故事
```
- 案例：巴西电商9张CSV → 10万订单入库 → 运费占比16.57% → 交互式仪表盘
- 一键刷新：双击 `一键更新.py`

### 链2：做网页（已跑通）
```
有想法 → 描述给Claude Code → 出HTML → cloudflared生成外链 → 发给别人
```
- 案例：Hello Kitty生日页、工作台、简历

### 链3：知识沉淀（已跑通）
```
学新东西 → 用白话说人话 → Obsidian写笔记 → 加上双向链接 → 以后翻回来
```
- 每次对话结束提醒自己写日记

### 链4：成本调研分析（暑假解锁）
```
去工厂观察 → 记原材料/人工/费用 → 回来整理数据 → 出成本结构报告
```
- 关键：见大叔前准备好观察提纲和自我介绍

### 链5：学习助手自动化（暑假解锁）
```
Coze设好规则 → 每天提醒复习六级 → 每周汇总进度 → 自动记录到飞书表格
```
- 不用写代码，拖方块就能搭

### 链6：内容半自动生产（大三解锁）
```
你定选题 → AI写文案 → 即梦出图 → Coze定时发布 → 飞书存档数据
```
- 前提：链1-5都跑熟了再碰这个

### 链7：双向智能遥控（搭建中）
```
微信发指令 → Coze Bot收到（云端24/7）→ 写指令到文件 → PC Python轮询 → Claude Code干活 → 结果回微信
```
- 关键：笔记本设「熄屏不睡眠」= 免费云服务器，月费 5 块电费
- 桥接方式：Coze 文件桥（最容易落地），以后可升级 HTTP 桥或 MCP 桥
- 这就是「土法全能智能体」：Coze 做编排 + Claude Code 做重活 + 千问做视觉 + 即梦做图

## 端对端自动化（并入自第007篇）

跟定时提醒的区别：端对端靠系统级触发器，不依赖AI在线，关机也能补跑。

**核心配方（3样东西）**：
1. Windows任务计划程序 → 触发器，管"什么时候跑"
2. Python脚本 → 工人，管"具体干什么"
3. QQ邮箱SMTP → 通道，管"推到手机哪里"

SMTP比喻：快递小哥。你把包裹（邮件）交给它，它负责送到手机QQ。需要QQ邮箱授权码（不是QQ密码），在QQ邮箱设置→账户→POP3/SMTP开启。

**已验证案例**：
| 场景 | 触发 | 产出 |
|------|------|------|
| 每日知识推送 | 每天8:00 | 随机抽笔记→AI提炼→发邮箱 |
| 每周学习周报 | 周日21:00 | 扫描日记→AI总结→发邮箱 |
| GitHub自动备份 | 每天23:00 | git add+commit+push |
| 六级冲刺 | 每天7:00 | 真题库随机10题→发邮箱 |

## 核心原则
- **先有活再招工**：不是工具越多越好，是每把刀都有菜要切
- **先跑通再优化**：一个链跑出结果了，再想怎么让它自动跑
- **功利优先**：低成本高回报的先搞，高成本不确定的不急
- **你是指挥的，不是干活的**：工具是工人，你是工头
