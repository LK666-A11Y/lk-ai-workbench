# MCP 和 RAG

> 创建时间：2026-05-25

## MCP — 万能插头
- 全称：Model Context Protocol
- 干什么：把外部系统（GitHub、数据库、ERP）接到 AI
- 比喻：钥匙，打开不同房间的门
- 费用：免费开源
- 我怎么用：装了一个 GitHub MCP，能直接管理仓库

## RAG — 智能翻书
- 全称：Retrieval-Augmented Generation（检索增强生成）
- 干什么：AI 先翻文档找到相关内容，再回答，不是凭空瞎编
- 比喻：考试前翻书，翻到那一页再回答
- 公司里：把规章制度、产品手册喂给 RAG，秒变智能客服

## 两者配合
```
公司数据库 → MCP 接进来 → RAG 翻记录 → AI 出答案
```
