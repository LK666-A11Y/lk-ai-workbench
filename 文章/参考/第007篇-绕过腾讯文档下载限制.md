# 绕过腾讯文档下载限制

> 创建时间：2026-05-26

## 场景

腾讯文档分享时，创建者可能关了「下载」和「复制」权限。普通手段拿不到内容。

## 解决方案

1. Edge 浏览器装 **GoFullPage** 插件（扩展商店搜）
2. 打开目标文档 → 点 GoFullPage 图标 → 一键截全页
3. 导出为 PDF
4. Claude Code 用 PyMuPDF 分页读取 PDF

## 原理

GoFullPage 滚动拼接 = 截图，绕过文字层面的权限控制。PDF 是图片格式，Claude Code 可以直接看图识别内容。

## 适用范围

不只是腾讯文档，所有「禁止下载 + 禁止复制」的网页文档都适用。
