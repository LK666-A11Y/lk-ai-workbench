# 视频字幕提取指南

> 创建时间：2026-05-25

Claude Code 看不了视频。但字幕是纯文字，扔给它就能处理。

---

## B站视频 → 字幕

| 工具 | 难度 | 用法 |
|------|------|------|
| **Bilibili Evolved**（推荐） | 低 | Edge 装插件 → 视频页点"下载字幕" → 导出 `.srt` |
| lux（命令行） | 中 | `lux -C 视频URL` 自动下载视频+字幕 |
| 唧唧Down（桌面软件） | 低 | 粘贴链接 → 勾选"下载字幕" |

`.srt` 文件就是文本，Claude Code 能直接读。

## 抖音视频 → 文字

- **抖音自带 AI 视频总结**：视频下方 → 点"AI 总结" → 自动生成文字摘要
- 复制文字直接扔给 Claude Code 分析
- 如果没 AI 总结按钮，你看完用话转述给我，效果一样、成本更低

## 通用做法

你看视频 → 用话转述重点 → 我帮你整理分析。这招成本最低、适用任何平台。
