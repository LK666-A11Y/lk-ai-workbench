## visual-translator（视觉翻译桥）

**触发词**：看图、识别、帮我看看这张图、截图、PDF第X页

### 流水线

**方式A：用户粘贴截图**
1. 截图保存：`python 学习/剪贴板存图.py 临时截图.png`
2. 千问识别：`python 学习/视觉翻译桥.py 临时截图.png "用户的问题"`
3. 展示结果

**方式B：用户给图片路径**
直接运行：`python 学习/视觉翻译桥.py <文件路径> "用户的问题"`

**方式C：PDF页面预览**
```python
import fitz
doc = fitz.open("PDF路径")
page = doc[页码-1]
pix = page.get_pixmap(dpi=200)
pix.save("临时pdf页.png")
```
然后走方式B。

**Python路径**：
```
export PATH="/c/Users/32655/AppData/Local/Programs/Python/Python312:$PATH" && python 脚本名.py
```

**成本**：千问VL约0.01元/张，100万tokens免费额度够看600+张。

## token-guard（Token消耗提醒）

**触发条件**：
- 3个以上独立任务
- 读取>50KB文件
- 连续处理>5张图
- 对话超过40轮

**提醒格式**：
```
⚡ token预估：本轮约 X,XXX tok ≈ ¥0.0X
   主要消耗：[来源]
   建议：[优化建议]
```

**估算规则**：
| 操作 | 消耗 |
|------|------|
| 系统提示词 | ~7,000 tok/轮 |
| 千问VL看一张图 | ~2,000 tok |
| 读大文件 | 字节数×0.33 |
| 搜索/WebFetch | ~1,000-3,000 tok |

## note-optimizer（笔记优化器）

**触发词**：优化笔记、整合笔记、合并笔记、检查重复、整理笔记库

**流程**：扫描全库→找重叠→建议合并→执行→更新链接→删旧文件

**合并判断**：
- 合并：同主题3篇以上、内容明显重叠
- 不合并：各自独立角度、仅2篇且侧重点不同
- 保留空编号，不重编号
