## 一、能做什么

| 类别 | 具体 | 举例 |
|------|------|------|
| 写代码 | Python、HTML、SQL | 生成分析脚本、做网页 |
| 数据分析 | 读CSV/Excel → SQL → 可视化 | 巴西电商10万订单 |
| 生成文件 | Word、Excel、PPT、PDF | 四件套一条命令 |
| 做网页 | HTML + ECharts | 仪表盘、生日页面 |
| 操作电脑 | 装/卸软件、清文件 | winget + 系统优化 |
| 查资料 | 联网搜索、读网页 | 工具定价、方案调研 |
| 管知识 | 写笔记、建链接 | 双向链接、工作流 |

### 不擅长的

| 类别 | 表现 | 正确做法 |
|------|------|---------|
| Word排版 | 能写内容，格式不精致 | AI出内容 + 手动套模板 |
| PPT设计 | 能塞文字图片 | AI出内容 + 自己拖布局 |
| 视频生成 | 只能拼图片 | 交给即梦/Seedance |

## 二、多工人并行

复杂任务拆成互不依赖的小块，同时扔给多个 Agent 并行处理。4件事一轮对话搞定。

| 场景 | 并行拆法 |
|------|----------|
| 简历投递 | 同时搜3个平台岗位 + 对比薪资 |
| 数据分析 | 同时跑4条SQL + 画2张图 |
| 学新概念 | 同时搜定义、搜案例、搜教程 |

**不用并行**：任务之间有关联（B需要A的结果）、非常简单的事。
