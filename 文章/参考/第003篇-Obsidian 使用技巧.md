# Obsidian 完全指南

> 创建时间：2026-05-25

## 核心功能

### 1. 双向链接 `[[]]`
- 笔记之间互相引用
- 写 `[[另一篇笔记]]` 自动创建链接
- 点链接直接跳过去

**你的用法：**
```
今天跑 SQL 发现运费占比 35%
→ 在日记里写 [[跨境电商利润分析]] 引用项目笔记
```

### 2. 标签 `#`
- 给笔记打标签
- 比如 `#SQL` `#跨境电商` `#业财融合`
- 点标签看到所有相关笔记

### 3. 图谱视图
- 左侧栏 → 点 Graph View
- 看到所有笔记之间的关联网
- 点越多、关联越多 = 知识越密

### 4. 模板
- 设置 → 核心插件 → 打开"模板"
- 创建模板笔记，每次新建用 Ctrl+T 插入

### 5. Dataview 插件（进阶）
- 把笔记当成数据库来查
- 以后笔记多了再装

## 导出笔记为 Word/PDF

Pandoc 是一个文档格式转换器，能把你的 `.md` 笔记变成 Word、PDF、HTML 等格式。

### 怎么用

1. 打开任意笔记
2. 按 **Ctrl+P** 打开命令面板
3. 搜索 **Pandoc**
4. 选你要的格式：
   - **Word (.docx)** → 交作业、写报告
   - **PDF** → 打印、发别人看
   - **HTML** → 做网页

### 文件存在哪

导出文件会放在**原笔记同一个文件夹**里，不会乱跑。

### 注意

- 导出一定会生成文件，没有"只预览"模式
- 点错了直接删掉就行，不影响原笔记

```
[打开仪表盘](../学习/仪表盘.html)
```

### 双向链接笔记
```
[[第1篇-2026-05-24 学习记录]]
```

| 写法 | 效果 |
|------|------|
| `[[笔记名]]` | 跳到另一篇笔记 |
| `[文字](路径)` | 打开电脑上的任意文件 |
