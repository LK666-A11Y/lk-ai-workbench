# 工具选择的判断力

> 创建时间：2026-05-26

## 1. 一张图多少钱？先算账再动手

**触发问题**："会不会太耗钱了"

**计算过程**：
- 千问 VL API：一张截图约 1500 tokens，0.008-0.02 元
- 一天最多 5 张图，一个月不到 1 元
- 新用户送 100 万 tokens，够看 600+ 张图
- 充 10 元用半年

**关键思维**：不要凭感觉说"贵"或"便宜"，拿数字说话。AI 调用的成本不是 0，但便宜到你几乎感觉不到。

**延伸**：以后遇到任何"做不做"的决策，先算三个账——时间、金钱、精力。低成本高回报的先冲。

## 2. 一万篇装得下吗？

**触发问题**："我现在笔记分类越来越多，要是有一百篇装得下吗" → "那要是一万篇呢"

**分析**：

| 规模 | 策略 | 瓶颈 |
|------|------|------|
| 20-50 篇 | 文件夹分类够用 | 无 |
| 50-500 篇 | 三位数编号 + 细分文件夹 | 文件夹层级别超 3 层 |
| 500-10000+ 篇 | 靠搜索 + 双向链接，不翻文件夹 | 依赖 Obsidian 的图视图和搜索 |

**关键认知**：不要用 20 篇的思维设计 10000 篇的系统，但也不要为 10000 篇提前过度设计。现在做三件事就够了：三位数编号、每 50 篇细分一个子文件夹、养成搜索习惯。

## 3. CC Switch：好工具，但不是现在

**触发问题**："为啥不用 CC Switch 里面弄呢"

**背景**：CC Switch 是个 GitHub 5 万星的开源工具，一键切换 Claude Code 的底层模型（DeepSeek/千问/GLM）。

**为什么现在不用**：
- 它是用来切换 Claude Code 的大脑（模型路由），不是用来加外部功能
- 翻译桥（调千问看图）是一个辅助脚本，跟模型切换是两回事
- 现在只有一个千问 API Key，没有需要切换的多个模型

**什么时候用**：以后想用 DeepSeek 当 Claude Code 的大脑来省钱，或者需要在多个模型间切换时再装。

**教训**：好工具 ≠ 现在需要的工具。装一个东西前先问：它解决我什么痛点？这个痛点我现在有吗？
