# 搞懂AI概念

> 创建时间：2026-05-26

## 1. 大模型 vs Agent：本质区别在哪

**触发问题**："不一样啊，大模型跟 agent 哪里一样"

**核心区别**：

| | 大模型（千问 App） | Agent（Claude Code） |
|---|-----------------|---------------------|
| 能干什么 | 聊天、回答、建议 | 聊天 + 操作文件 + 执行命令 |
| 看图后 | 描述完就停了 | 描述完直接帮你修 |
| 比喻 | 一个聪明的顾问 | 顾问 + 一双能干活的手 |

**关键洞察**：Agent 不只是多了双眼睛（多模态），是多了一双连着大脑的手。看图不是终点，看图后自动干活才是。

## 2. MCP、长记忆、向量数据库，别再混了

**触发问题**："跨文本长记忆对话是不是这个"（指着 MCP）

**三件事的区别**：

| 概念 | 是什么 | 比喻 |
|------|--------|------|
| MCP | 给 AI 接外设的插头（读数据库、发邮件） | USB 扩展坞 |
| 长记忆（CLAUDE.md + memory） | 每次开对话自动读你的档案 | 身份证 + 档案袋 |
| 向量数据库 | 把大段文档切成碎片存起来按需检索 | 图书馆索引系统 |

**我现在的配置**：CLAUDE.md + memory/ 已经实现了跨对话长记忆，不需要额外工具。闲鱼上卖什么"跨文本长记忆神器"的，大概率是包装这套东西——别买。

**教训**：新概念出现时先问三个问题——它是解决什么问题的？我现在有这个需求吗？我已经有的工具是不是已经在解决了？
